# Supported account formats (one account per line):
#
# FORMAT 1 (Recommended when EVM master and AGW Signer keys differ):
#   ID:EVM_PRIVATE_KEY:SIGNER_PRIVATE_KEY
#   Example:
#   1:0x0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef:0xabcdef0123456789abcdef0123456789abcdef0123456789abcdef0123456789
#   2:0x123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef0:0xbcdef0123456789abcdef0123456789abcdef0123456789abcdef0123456789a
#
# FORMAT 2 (If using a single private key for both EVM and AGW):
#   ID:PRIVATE_KEY
#   Example:
#   1:0x0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef
#
# FORMAT 3 (Plain private key only):
#   0x0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef
#
# ------------------------------------------------------------------------------
# ℹ️ GUIDE:
# - EVM_PRIVATE_KEY: Exported from your standard MetaMask / Rabby wallet.
# - AGW_SIGNER_PRIVATE_KEY: Exported from https://portal.abs.xyz via
#   profile settings (Settings -> Embedded Wallet -> Export Private Key)
#   or via browser storage (F12 -> Application -> Local Storage).
