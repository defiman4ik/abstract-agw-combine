Полноценный профессиональный комбайн для автоматизации работы со смарт-кошельками **Abstract Global Wallet (AGW)** в сети **Abstract Mainnet** ([portal.abs.xyz](https://portal.abs.xyz/)).

Разработано специально для аккаунтов, созданных через стандартные EVM-кошельки (MetaMask / Rabby / приватные ключи) с использованием официального SDK `@abstract-foundation/agw-client` и стандарта **Native Account Abstraction (EIP-712)**.

---

## 🌟 Возможности и Режимы работы

```text
================================================================
         ABSTRACT GLOBAL WALLET (AGW) AUTOMATION BOT            
        Account Abstraction • Liquidity • Swapper • Bridge      
================================================================
[?] Выберите режим работы:
 > 1. 📊 Сканировать аккаунты (Балансы AGW, EOA, токены и ликвидность)
   2. 💧 Снять ликвидность с протоколов (Aborean, KONA, Sakura Swap)
   3. 🔄 Обменять все токены в ETH (Swap to ETH + Unwrap WETH)
   4. 💸 Вывести ETH на EVM-кошельки (Withdraw to EVM)
   5. ⚡ Полный цикл (Снять ликвидность -> Обмен токенов в ETH -> Вывод ETH на EVM)
   6. 🌐 Сменить язык / Change language / Змінити мову
   7. 🚪 Выход
```

### 1. 📊 Сканирование аккаунтов (Checker & Analytics)
- Детерминированный расчет и определение адресов смарт-контрактов AGW.
- Опрос через **Multicall3** за один запрос:
  - Балансы нативного ETH на AGW и EOA аккаунтах подписанта.
  - Балансы стейкингового `absETH`.
  - Токены экосистемы (`WETH`, `USDC`, `USDT`, `gtBTC`, `KONA`, `PEARL`, `PENGU` и др.).
  - Залоченная ликвидность в пулах DEX.
- Вывод наглядной цветной сводной таблицы в консоль и автоматический экспорт стилизованного отчета в **Excel (.xlsx)** в папку `reports/`.

### 2. 💧 Снятие ликвидности (Liquidity Remover)
- Автоматическая проверка залоченных средств в протоколах:
  - **Aborean DEX**
  - **KONA Protocol**
  - **Sakura Swap**
- Сбор накопленных комиссий и вывод ликвидности обратно на баланс AGW.

### 3. 🔄 Обмен всех токенов в ETH (Token Swapper)
- **WETH -> ETH**: мгновенный unwrap 1:1 через официальный контракт WETH без комиссий агрегаторов и без проскальзывания (slippage).
- **ERC-20 -> ETH**: автоматический выбор лучших маршрутов через DEX-агрегатор **Relay API**, выполнение approve и свапов.

### 4. 💸 Вывод ETH на EVM (Withdraw to EVM)
- Расчет доступного баланса ETH с сохранением настраиваемого безопасного резерва на газ (`GAS_RESERVE_ETH`).
- Перевод средств на EVM-кошелек подписанта (`SAME_AS_EOA`) или на индивидуальные адреса из `recipients.txt` (`FROM_FILE`).

### 5. ⚡ Полный цикл (Full Cycle)
- Автоматический комбо-пайплайн для очистки аккаунтов:
  `Снятие ликвидности -> Обмен всех найденных токенов в ETH -> Вывод ETH на EVM`.

### 6. 🌐 Мультиязычность (i18n)
- Переключение языка в реальном времени прямо в интерактивном меню или через файл `settings.py` (`LANGUAGE = "RU"` / `"EN"` / `"UA"`).

> 🚀 **Upcoming Feature**: Модули продвинутого прогрева (Warmup) и ежедневного голосования (Upvote) находятся на ветке `feature/warmup-upvote` и готовятся к следующему релизу!

## 🛡️ Безопасность и Anti-Sybil механизмы
- **Статичная привязка прокси 1-к-1**: каждый аккаунт жестко привязан к своему прокси из `proxies.txt`, что исключает смешивание IP при случайном порядке запуска.
- **Раздельные профили задержек**:
  - `SLEEP_BETWEEN_ACCOUNTS`: длительные паузы между транзакциями (например, 10–30 мин).
  - `SLEEP_BETWEEN_ACCOUNTS_SCAN`: быстрые паузы для сканирования (20–30 сек).
- **Контроль порядка выполнения (`SHUFFLE_ACCOUNTS`)**:
  - Транзакционные режимы перемешивают порядок аккаунтов для предотвращения кластеризации.
  - Режим сканирования всегда сохраняет строгий порядок (1..N) для удобного мониторинга.
- **Динамический резерв газа (`GAS_RESERVE_ETH`)**: рандомизированный остаток не дает опустошить балансы «в ноль».

## 📦 Установка и настройка

### 1. Системные требования
- **Python**: версия `3.10` или выше.
- **Node.js**: версия `18.x` или выше.

### 2. Клонирование и установка зависимостей

```bash
# Клонирование репозитория
git clone https://github.com/your-username/abstract-agw-bot.git
cd abstract-agw-bot

# Установка зависимостей Node.js
npm install

# Установка зависимостей Python
pip install -r requirements.txt
```

### 3. Конфигурация аккаунтов

Создайте файл `privatekeys.txt` на основе `privatekeys.example.txt`:

```text
# Формат: ID:EVM_PRIVATE_KEY:SIGNER_PRIVATE_KEY
1:0x0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef:0xabcdef0123456789abcdef0123456789abcdef0123456789abcdef0123456789
2:0x123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef0:0xbcdef0123456789abcdef0123456789abcdef0123456789abcdef0123456789a
```
*(Также поддерживается формат одного ключа `ID:PRIVATE_KEY` или просто приватный ключ).*

#### 🔑 Что такое EVM Key и Signer Key и где их взять?
1. **EVM Private Key (EOA)**:
   - Обычный приватный ключ вашего основного кошелька (MetaMask, Rabby и т.д.).
   - **Зачем нужен**: Используется для депозита ETH с EOA на AGW в режиме прогрева (`Warmup`), а также как адрес получателя по умолчанию при выводе средств.
   - **Где взять**: В вашем кошельке (MetaMask: *Реквизиты счета -> Экспортировать закрытый ключ*).

2. **AGW Signer Private Key (Подписант смарт-кошелька)**:
   - Так как **AGW (Abstract Global Wallet)** является смарт-контрактом (Account Abstraction EIP-712), транзакции от его имени подписываются уполномоченным сессионным ключом-подписантом (Signer).
   - **Способ 1 (Один ключ для обеих ролей)**:
     - Если ваш смарт-кошелек AGW управляется напрямую вашим EOA-ключом, вы можете указать один и тот же ключ дважды или использовать формат `1:PRIVATE_KEY`.
   - **Способ 2 (Экспорт с portal.abs.xyz)**:
     - Перейдите на [portal.abs.xyz](https://portal.abs.xyz) и подключите кошелек.
     - Откройте настройки кошелька (**Settings / Security**).
     - В блоке встроенного кошелька (Privy / Embedded Wallet) выберите **"Export Private Key"** и сохраните ключ.
   - **Способ 3 (Через хранилище браузера F12)**:
     - Нажмите `F12` на сайте `portal.abs.xyz` -> вкладка `Application` -> `Local Storage` -> `https://portal.abs.xyz`.
     - Данные авторизованного сессионного подписанта сохраняются под ключами с префиксом `privy:...`.

### 4. Конфигурация прокси

Создайте файл `proxies.txt` на основе `proxies.example.txt`:

```text
http://username:password@ip:port
socks5://username:password@ip:port
```

### 5. Настройка параметров

Откройте `settings.py` и задайте желаемые настройки:
- `LANGUAGE`: язык интерфейса по умолчанию (`"EN"`, `"UA"`, `"RU"`).
- `GAS_RESERVE_ETH`: диапазон оставляемого на газ ETH (например, `[0.007, 0.015]`).
- `SLEEP_BETWEEN_ACCOUNTS`: пауза между транзакциями аккаунтов.
- `WARMUP_MODE`, `DO_SWAP`, `CREATE_LP`, `STAKE_FARM`: стратегия прогрева.
- `UPVOTE_LOOP`: бесконечный ежедневный цикл голосования.
